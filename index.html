数据备份与同步

开启「自动备份文件」后，每次保存数据都会自动同步写入该 JSON 文件；打开工作台时自动从该文件恢复数据（需 Chrome / Edge 桌面版）。

「导出 / 导入」为通用 JSON，可在不同设备或手机间迁移数据。

云端同步（Supabase）

填入 Supabase 项目信息即可开启多设备自动同步与实时更新。配置仅保存在本机浏览器，不会上传到任何第三方。

还没有 Supabase？去 supabase.com 免费建项目，并在 SQL Editor 运行本项目附带的建表脚本（见 supabase_schema.sql）即可。

多设备共享数据（电脑 ⇄ 手机）

本工作台是同一个网页（PWA），电脑和手机用同一个网址即可共享数据，无需单独开发手机版。

① 怎么把工作台变成手机 App？
  1. 手机浏览器（安卓 Chrome / iPhone Safari）打开工作台网址
  2. 安卓：点右上角 ⋮ →「添加到主屏幕」
    iPhone：点底部「分享」→「添加到主屏幕」
  3. 桌面出现「我的工作台」图标，点开即全屏 App，离线也能用
② 电脑和手机怎么共享同一份数据？
  1. 在 电脑 和 手机 上分别用同一个网址打开工作台
  2. 两端都进入本页「云端同步（Supabase）」，填入同一组 Project URL + anon key
  3. 两端都点「连接并同步」（每台新设备首次需填一次，之后自动记住）
  4. 完成！任一端保存/打卡，另一端实时自动刷新（已开启 Realtime）
③ 注意事项
  • Supabase 建表脚本（supabase_schema.sql）只需运行一次
  • 当前为「不登录」共享模式，数据对填了同一 key 的人可见，适合个人使用
  • 若某端显示「未连接」，检查该端是否填过 URL+key 并点过连接
  • 换手机需重新填写一次 Supabase 信息（配置存本机，不上云）
